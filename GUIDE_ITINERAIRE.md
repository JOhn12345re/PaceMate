# 🧭 Guide du Planificateur d'Itinéraire - PaceMate

## 🎯 Vue d'Ensemble

Le **Planificateur d'Itinéraire** PaceMate te permet de créer des parcours personnalisés d'un point A à un point B, avec possibilité d'ajouter des étapes intermédiaires !

---

## 🚀 Démarrage Rapide

### En 3 Étapes

1. Clique sur **"🧭 Planifier itinéraire"** en haut de la carte
2. Choisis ton **point d'arrivée** sur la carte
3. Clique sur **"🧭 Calculer l'itinéraire"**

C'est fait ! Ton itinéraire est tracé ! 🎉

---

## 📍 Définir les Points

### Point de Départ (🅰️)

Par défaut, ton **position actuelle** est utilisée comme point de départ.

**Pour changer :**
1. Clique sur **"📍 Choisir sur la carte"** (Point de départ)
2. Clique sur la carte où tu veux commencer
3. Le marqueur vert 🅰️ apparaît

**Astuce Pro :** Tu peux **glisser-déposer** le marqueur pour l'ajuster !

### Point d'Arrivée (🅱️)

1. Clique sur **"📍 Choisir sur la carte"** (Point d'arrivée)
2. Clique sur la carte où tu veux terminer
3. Le marqueur rouge 🅱️ apparaît

**Astuce Pro :** Tu peux aussi **glisser-déposer** ce marqueur !

### Étapes Intermédiaires (1️⃣2️⃣3️⃣...)

Ajoute des points de passage pour créer un parcours complexe !

1. Clique sur **"➕ Ajouter étape intermédiaire"**
2. Choisis le point sur la carte
3. Les marqueurs jaunes numérotés apparaissent
4. Répète pour ajouter plus d'étapes

**Supprimer une étape :** Clique sur le bouton **🗑️** à côté de l'étape

---

## 📊 Informations de l'Itinéraire

Après avoir calculé l'itinéraire, tu obtiens :

### 📏 Distance
- Distance totale en kilomètres
- **Exemple :** 5.23 km

### ⏱️ Temps Estimé
- Basé sur une allure moyenne de 6 min/km
- **Exemple :** 31 min

### ⚡ Allure Suggérée
- Vitesse recommandée pour compléter le parcours
- **Exemple :** 6 min/km

### 🔥 Calories
- Estimation des calories brûlées
- Environ 60 kcal/km
- **Exemple :** 314 kcal

## 🎮 Actions Disponibles

### 🏃‍♂️ Démarrer la Navigation

Lance le **mode navigation** avec :
- Interface en bas de l'écran
- Instructions en temps réel
- Distance restante
- **Récompense :** +50 XP au démarrage, +100 XP et +50 coins à la fin !

### 💾 Sauvegarder l'Itinéraire

**Pourquoi sauvegarder ?**
- Réutiliser tes parcours favoris
- Créer une collection de routes
- Gagner du temps

**Comment :**
1. Clique sur **"💾 Sauvegarder l'itinéraire"**
2. Donne un nom à ton parcours
3. C'est sauvegardé localement !

### 📂 Charger un Itinéraire Sauvegardé

En bas du panneau, tu verras **"💾 Mes itinéraires sauvegardés"** :
- **Cliquer** sur un itinéraire pour le charger
- **📂** : Charger l'itinéraire
- **🗑️** : Supprimer l'itinéraire

### 📤 Partager

Génère un **lien unique** de ton itinéraire :
- Copié automatiquement dans le presse-papier
- Partage avec tes amis
- Ils peuvent recréer ton parcours !

### 🗑️ Effacer

Nettoie tout et recommence à zéro :
- Supprime les marqueurs
- Efface l'itinéraire
- Réinitialise les champs

## 💡 Cas d'Usage

### 1. Course Matinale Planifiée

**Scénario :** Tu veux courir 5 km demain matin.

**Étapes :**
1. Ouvre le planificateur
2. Définis ton point de départ (maison)
3. Cherche un point à ~2.5 km (aller)
4. Ajoute une étape intermédiaire (fontaine pour boire)
5. Le retour complète l'itinéraire à 5 km
6. **Sauvegarde** : "Course matinale 5K"

**Résultat :** Itinéraire prêt pour demain ! ✅

### 2. Découverte de Nouveau Quartier

**Scénario :** Explorer un nouveau quartier en courant.

**Étapes :**
1. Point de départ : Parking du quartier
2. Ajoute 3-4 étapes intermédiaires (points d'intérêt)
3. Point d'arrivée : Retour au parking
4. Calcule : Tu as un circuit de découverte !
5. **Lance la navigation** pour explorer

**Résultat :** Découverte guidée ! 🗺️

### 3. Entraînement avec Ami

**Scénario :** Rejoindre un ami à mi-chemin.

**Étapes :**
1. Point de départ : Chez toi
2. Étape 1 : Point de rencontre avec l'ami
3. Point d'arrivée : Parc pour courir ensemble
4. **Partage** le lien à ton ami
5. Il peut voir le même itinéraire !

**Résultat :** Coordination parfaite ! 👥

### 4. Parcours de Compétition

**Scénario :** Préparer une course de 10 km.

**Étapes :**
1. Crée un circuit de 10 km exact
2. Ajoute des étapes tous les 2 km (repères)
3. Sauvegarde : "Entraînement 10K"
4. Utilise-le chaque semaine
5. Suis ta progression !

**Résultat :** Entraînement structuré ! 🏃‍♂️

## 🎯 Stratégies Avancées

### Créer un Circuit (Boucle)

Pour revenir au point de départ :
1. Définis ton départ
2. Ajoute 2-3 étapes intermédiaires
3. Définis l'arrivée **au même endroit** que le départ
4. Tu as une boucle !

### Parcours Multi-Terrains

Alterne entre différents types de terrain :
1. Départ : Zone urbaine
2. Étape 1 : Entrée du parc (nature)
3. Étape 2 : Sortie du parc
4. Arrivée : Retour en ville

### Itinéraire de Sécurité

Pour courir en toute sécurité la nuit :
1. Sélectionne uniquement des rues éclairées
2. Évite les zones isolées
3. Reste dans des quartiers animés
4. Ajoute des étapes dans des lieux publics

### Défi Distance

Créer un parcours d'une distance précise :
1. Place ton arrivée
2. Calcule
3. Si trop court : Ajoute des étapes intermédiaires
4. Si trop long : Rapproche l'arrivée
5. Ajuste jusqu'à la distance voulue !

## 🔧 Options Avancées

### Personnaliser l'Allure

Dans le code (`app.js`, ligne ~2530), tu peux changer :

```javascript
const averagePace = 6; // min/km
```

Change cette valeur pour ajuster les estimations de temps.

### Modifier les Calories

```javascript
const calories = Math.floor(totalDistance * 60); // 60 cal/km
```

Ajuste le multiplicateur selon ton poids et intensité.

### Changer les Couleurs

Dans `styles.css`, cherche `.planned-route-line` :

```css
stroke: #FF6B35; /* Couleur de la ligne */
```

## ⚙️ Paramètres et Préférences

### Unités de Mesure

Actuellement en **kilomètres**. Pour passer en miles, modifie dans `app.js` :

```javascript
totalDistance = totalDistance / 1000; // km
// Remplace par :
totalDistance = totalDistance / 1609.34; // miles
```

### Vitesse par Défaut

Ajuste l'allure de référence selon ton niveau :
- **Débutant** : 7-8 min/km
- **Intermédiaire** : 5-6 min/km
- **Avancé** : 4-5 min/km
- **Pro** : 3-4 min/km

## 🐛 Dépannage

### Le panneau ne s'affiche pas
✅ Recharge la page (F5)  
✅ Vérifie que tu es sur la vue "Carte"  
✅ Clique bien sur le bouton "🧭 Planifier itinéraire"  

### Les marqueurs ne bougent pas
✅ Ils doivent être **glissés**, pas cliqués  
✅ Clique et maintiens enfoncé  
✅ Glisse puis relâche  

### L'itinéraire ne se calcule pas
✅ Vérifie que DÉPART ET ARRIVÉE sont définis  
✅ Les deux inputs doivent afficher des coordonnées  
✅ Regarde si les marqueurs 🅰️ et 🅱️ sont sur la carte  

### Les itinéraires sauvegardés ne se chargent pas
✅ Ils sont stockés localement (LocalStorage)  
✅ Ne vide pas le cache du navigateur  
✅ Utilise toujours le même navigateur  

### Le partage ne fonctionne pas
✅ Certains navigateurs bloquent l'accès au presse-papier  
✅ Le lien est toujours généré (vérifie les notifications)  
✅ Copie manuellement si besoin
