## 💬 Commandes CodeRabbit

Une fois la PR créée, tu peux utiliser :

```
@coderabbitai review
```
Force une nouvelle analyse complète

```
@coderabbitai summarize
```
Résumé de l'analyse

```
@coderabbitai explain app.js:2426
```
Explique une ligne spécifique

```
@coderabbitai help
```
Liste toutes les commandes

## 📝 Après l'analyse

1. **Lire attentivement** les commentaires CodeRabbit
2. **Prioriser** les corrections :
   - 🔴 Critiques → Immédiat
   - 🟠 Importantes → Cette semaine
   - 🟡 Nice-to-have → Plus tard

3. **Corriger** dans des commits séparés
4. **Push** pour re-déclencher l'analyse
5. **Merger** quand tout est vert ✅

## 🎓 Apprendre de CodeRabbit

CodeRabbit est **pédagogique**. Il :
- Explique pourquoi un code est problématique
- Propose des solutions concrètes
- Donne des exemples de code corrigé
- Partage les bonnes pratiques
