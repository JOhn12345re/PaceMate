### 2. 🏅 Système de Certification

#### 5 Niveaux de Certification
- ⭐⭐⭐⭐⭐ **Or** : Homologation officielle (FFA), surveillance 24/7
- ⭐⭐⭐⭐ **Argent** : Validé autorités locales, entretien régulier
- ⭐⭐⭐ **Bronze** : Vérifié communauté, entretien mensuel
- ✓ **Communautaire** : Proposé par utilisateurs, en vérification

#### 3 Niveaux de Sécurité
- 🔒 **Maximale** : Éclairage 100%, vidéosurveillance, voie dédiée
- 🔓 **Élevée** : Éclairage 70%+, patrouilles, semi-dédiée
- ⚠️ **Standard** : Éclairage partiel, zone fréquentée jour

### 3. 🏃 Types de Parcours

#### 🏟️ Pistes Athlétiques Officielles
- Homologuées FFA
- Surface tartan/cendrée
- Mesures exactes

#### 🌳 Parcs Urbains

#### 🏖️ Parcours Côtiers


## 🎯 Utilisation

### Pour l'Utilisateur

1. **Ouvrir le panneau**
   - Cliquer sur "🛤️ Parcours sécurisés" sur la carte

2. **Filtrer les parcours**
   - Choisir le type (piste, parc, urbain...)
   - Sélectionner la distance
   - Filtrer par sécurité
   - Cocher "Accessibilité PMR" si besoin

3. **Voir les détails**
   - Cliquer sur une carte de parcours
   - Modal complet s'affiche
   - Voir toutes les infos

4. **Utiliser le parcours**
   - "🗺️ Voir sur la carte" : Affiche le tracé
   - "▶️ Démarrer" : Lance la course
   - "📤 Partager" : Copie le lien

### Pour le Développeur

```javascript
// Ouvrir le panneau
openSafePathsPanel();

// Filtrer
filterSafePaths();

// Afficher sur carte
viewPathOnMap(pathId);

// Démarrer un parcours
startSafePath(pathId);
```
