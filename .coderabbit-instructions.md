# 🐰 Instructions pour CodeRabbit

Cher CodeRabbit,

Merci d'analyser ce projet **PaceMate v3.0.0** en profondeur.

## 🎯 Contexte du projet

PaceMate est une **application full-stack de running sociale** avec :
- Frontend vanilla JavaScript + Leaflet.js
- Backend Node.js + Express + MongoDB
- WebSocket temps réel avec Socket.IO
- 6 mini-jeux multijoueurs
- Système de gamification complet

## 🔍 Points d'attention spécifiques

### 1. Sécurité 🔒

**Priorité maximale**. Vérifie :
- [ ] Pas de secrets exposés (JWT_SECRET, clés API)
- [ ] Validation stricte des inputs (XSS, injections)
- [ ] Authentification JWT robuste
- [ ] Configuration CORS appropriée
- [ ] Rate limiting efficace
- [ ] Hash bcrypt des mots de passe
- [ ] Requêtes MongoDB sécurisées (injections NoSQL)

### 2. app.js (2900+ lignes)

Ce fichier est **très volumineux**. Suggère :
- Découpage en modules
- Extraction de fonctions
- Réduction de la complexité
- Amélioration de la maintenabilité

Sections à analyser particulièrement :
- Gestion de la carte (lignes 50-600)
- Mini-jeux (lignes 1400-2000)
- Planificateur d'itinéraire (lignes 2200-2600)

### 3. Backend API

Vérifie pour **chaque route** :
- Authentification JWT présente
- Validation des données d'entrée
- Gestion des erreurs async/await
- Réponses HTTP cohérentes
- Logs appropriés

### 4. Performance

- Requêtes MongoDB avec index ?
- Pagination sur les listes ?
- Fuites mémoire potentielles ?
- Optimisations Socket.IO ?
- Cache bien configuré ?

### 5. Tests

Les tests Cypress sont-ils :
- Complets ?
- Bien structurés ?
- Couvrant les cas d'erreur ?
